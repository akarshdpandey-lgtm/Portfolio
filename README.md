# Akarsh Pandey — 3D Portfolio

AI, Computer Vision & Embedded Systems Developer.

This is the exported static build of the 3D portfolio website (single-file `index.html`).

## Run locally
Open `index.html` in a browser, or serve the folder:
```bash
python3 -m http.server 8000
```

## Contact form
The contact form sends queries to the owner's email via FormSubmit + mailto fallback.

- Phone and date of birth are intentionally left out for privacy.
